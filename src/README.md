# Introduction

Ce site web est destiné à accueillir quelques TP de Reseaux pour des étudiants de niveau BTS.

Dans les TP on aborde les notions suivantes :
- Configuration IP
- Configuration d'interfaces
- Diagnostic trivial de problèmes de connexions
- Types d'équipements reseaux
- Creation d'un cluster de 5 noeuds avec Proxmox

La mise en page de ce site est réalisée à partir du template de wiki [mdbook](https://github.com/rust-lang/mdBook).
